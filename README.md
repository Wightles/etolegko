# Тест скорости интернета

Консольный скрипт делает 10 последовательных запросов к указанному URL. Каждый ответ полностью скачивается перед началом следующего запроса.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 download_speed.py https://example.com/file.bin
```

Таймаут одного запроса можно изменить:

```bash
python3 download_speed.py https://example.com/file.bin --timeout 60
```

Скрипт выводит среднее время запроса, общий объём скачанных данных и среднюю скорость скачивания.

Единица объёма и скорости: `MiB`, где 1 MiB = 1024² байт. Скорость указана в `MiB/s` и рассчитывается как общий объём данных, делённый на суммарное время десяти запросов.

## Проверка

```bash
python3 -m unittest -v
```

## Веб-интерфейс

Запустите локальный сервер:

```bash
python3 -m http.server 7777
```

Откройте в браузере `http://127.0.0.1:7777/web/` и укажите URL ресурса.

Браузер разрешает JavaScript читать только ответы с CORS. Для проверки используйте URL, сервер которого отдаёт заголовок `Access-Control-Allow-Origin`.
